방법 1

마법 북마크(북마크릿) 활용

상단의 초록색 [⭐ 하원초6 엔트리로그인] 버튼을 컴퓨터실 브라우저 북마크바에 등록해두면, 엔트리 로그인 화면에서 클릭 한 번으로 학생 번호창이 열려 즉시 로그인됩니다.

방법 2

본 포털 페이지 활용 (확장 프로그램과 연동)

확장 프로그램이 설치된 PC에서는 학생이 번호 카드를 누르면 엔트리 로그인 창이 열리면서 아이디와 비밀번호가 자동으로 입력되고 바로 로그인됩니다. 확장 프로그램이 없는 PC에서는 아이디가 클립보드에 복사되므로 아이디 칸에 붙여넣기(Ctrl+V)하면 됩니다.

방법 3

크롬/웨일 확장 프로그램

함께 제공된 chrome_extension 폴더를 브라우저 '확장 프로그램 관리'에 등록하시면, 엔트리 로그인 창에 1~15번 버튼이 항상 고정되어 더 간편합니다.
