엔트리 원클릭 자동 로그인 포털

학생 여러분! 자기 번호를 클릭하면 엔트리 로그인 창이 열리고 아이디와 비밀번호가 자동으로 입력됩니다.

💻 학생 컴퓨터 1회 설치 (이걸 해야 자동 로그인이 됩니다!)

컴퓨터마다 딱 한 번, 오른쪽 설치 파일을 받아 압축을 풀고 설치.bat을 더블클릭하세요. 크롬·웨일·엣지에 자동 로그인 프로그램이 저절로 설치됩니다. (약 30초, 설치 중 마우스·키보드 건드리지 않기)
설치가 끝나면 번호 카드를 누르는 것만으로 아이디·비밀번호가 입력되고 로그인됩니다.

⬇️ 설치 파일 받기

⭐ 설치가 어려운 컴퓨터라면: 1초 마법 북마크

오른쪽 버튼을 마우스로 꾹 눌러 웹 브라우저 상단의 [북마크바(즐겨찾기)]로 끌어다 놓으세요! (북마크바가 안 보이면 Ctrl+Shift+B)
번호 카드를 눌러 열린 엔트리 창에서 이 북마크만 누르면 바로 로그인됩니다.

왜 설치가 필요한가요?

웹페이지는 다른 사이트 칸을 채울 수 없어요

이 포털은 엔트리와 다른 사이트라서, 브라우저 보안 규칙상 엔트리 로그인 칸에 직접 글자를 넣을 수 없습니다. 그래서 각 컴퓨터의 브라우저에 작은 확장 프로그램을 한 번 설치해야 자동 입력이 됩니다.

방법 1 (추천)

설치 파일로 자동 설치

상단 [⬇️ 설치 파일 받기] → 압축 풀기 → 설치.bat 더블클릭. "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행]. 크롬·웨일·엣지 중 설치된 브라우저에 자동으로 들어갑니다. 설치 후 번호 카드만 누르면 끝입니다.

방법 2

마법 북마크 (설치 없이)

파란색 [⭐ 하원초6 엔트리로그인] 버튼을 북마크바로 끌어다 놓습니다. 번호 카드를 눌러 열린 엔트리 창에서 북마크를 한 번 누르면 로그인됩니다. 엔트리에 바로 들어간 경우엔 1~15번 번호판이 뜹니다.

방법 3

직접 설치 (자동 설치가 안 될 때)

주소창에 chrome://extensions 입력 → 오른쪽 위 [개발자 모드] 켜기 → [압축해제된 확장 프로그램을 로드합니다] → 설치 파일을 푼 폴더 안의 chrome_extension 폴더 선택.
